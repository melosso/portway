# Reporting Security Vulnerabilities

**Report a security issue in a Portway product or service through a private security vulnerability report at https://github.com/melosso/portway/security/advisories/new. Security issues can also be reported by email to [security@melosso.com](mailto:security@melosso.com).** Melosso opens a [GitHub Security Advisory](https://github.com/melosso/portway/security/advisories) on the reporter's behalf to track the fix.

We value the independent security researchers who find vulnerabilities and work with the Melosso team to issue fixes to users. Melosso credits every researcher in the release notes of the fix. Credit requires responsible disclosure, including:

- The researcher does not publish the vulnerability before Melosso releases a fix for it.
- The researcher does not disclose exact details of the issue, for example through exploits or proofs of concept.
